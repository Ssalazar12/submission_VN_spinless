
# VN measurment kicks

This is the trimmed down version containing only the files necessary to reproduce all the figures in the submission. For the full repo including exploratory analysis refer to https://github.com/Ssalazar12/qpc_spinless.
The repository includes a requirements.txt with the required packacge version to generate a python virtual environment. This repo contains the code for the _Wavepacket-based Unitary Measurement Kicks_ manuscript, 
where a a single unitary Von Neumann measurement kick between a QPC and a qubit is implemented using a Gaussian wavepacket. This repor generates a set of data from an exact diagonalization algorithm implemented 
in python and then produces a consolidated dataset a processing jupyter notebook for porcessing. This also generates all the figures included in the manuscript 

## Data generation

The script qutip_tools.py is a custom packagr with helper functions for the raw data generation and the reading and processing of it.

The raw data is generated by running qpc_qubit_exact_diag.py with a given set of parameters (specified in the manuscript. The script does a parameter sweep and outputs a .h5 to the folder exact_diag_new file representing each configuration.

The processed data sets consist of .csv files generated by manuscript_figures.ipynb in the "Generate analysis dataframe and save it" section, which is commented out computational speed reasons. To 
generate the .csv for each parameter sweep one most indicate the folder where the raw data for each sweep is stored. We include a helper function get_file_names_on in qutip_tools.py that filters the raw data files based on the desired parameter values to limit the size of the .csv files. In the manuscript there are 3 data sets: One for the main text and two for the appendices. 

This same notebook is responsible for loading already existing datasets and generating the figures found in the manuscript which are saved in plots/manuscript_figs.
